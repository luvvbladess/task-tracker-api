# Task Tracker API

Небольшой пет-проект, апишка для управления тасками и проектами. Делал чисто для себя чтобы пощупать асинки и фастапи + попрактиковаться в архитектуре.

Стек:
- Python 3.11
- FastAPI
- PostgreSQL + asyncpg
- SQLAlchemy + Alembic

Что внутри:
- Спроектировал и реализовал REST API на Python (FastAPI) с авторизацией через JWT
- Поддержка ролей: администратор, участник проекта - разграничение прав доступа
- База данных: PostgreSQL, миграции через Alembic, связи many-to-many между задачами и тегами
- Реализовал фильтрацию и пагинацию списка задач через query-параметры
- Настроил логирование запросов и обработку ошибок через middleware
- Деплой в Docker-контейнере, CI-пайплайн через GitHub Actions (линтер + тесты)

## Как запустить

Можно просто поднять через докер:

```bash
docker-compose up -d
```

Потом стучимся на `http://localhost:8000/docs` и там будет свагер со всеми ручками.

Если локально разворачивать:
1. Накатить либы `pip install -r requirements.txt`
2. Поднять постгрес
3. Настроить `.env` (если надо, дефолты в `app/core/config.py` лежат)
4. Применить миграции: `alembic init alembic` (если с нуля) и потом `alembic upgrade head`
5. Старт `uvicorn app.main:app --reload`
